# Domäne verstehen

In den Unterordnern finden sich viele Beispiele von ersten Analyseergebnissen.
Grundlage bildeten in den meisten Fällen Internet-Recherchen durch die KI selbst.
Die einzelnen Beispiele sollen einen Eindruck geben, wie Concept-Maps, Domänenmodelle
oder Personas aussehen könnten. Sie sind noch nicht aufeinander abgestimmt!
