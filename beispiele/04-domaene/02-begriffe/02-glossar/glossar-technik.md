#Glossar technische Begriffe, Assistenzsysteme (ChatGPT, August 2026)

| Begriff                                                                                      | Definition                                                                                                                                                                                                                                                                                                                                                                                                                                       | Fundstelle                                                                                                      |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| **AAL – Ambient Assisted Living**                                                            | Sammelbegriff für Methoden, Konzepte, elektronische Systeme, Produkte und Dienstleistungen, die Menschen – insbesondere im Alter – im Alltag situationsabhängig und möglichst unaufdringlich unterstützen. AAL-Lösungen sind nutzerzentriert, in das Lebensumfeld integriert, anpassbar und häufig vernetzbar.                                                                                                                                   | Bundesministerium für Wirtschaft und Energie, *Ambient Assisted Living*. ([Bundeswirtschaftsministerium][1])    |
| **Aktivierungswort / Wake Word / Hotword**                                                   | Wort oder kurze Phrase, mit der ein Sprachassistent aktiviert beziehungsweise auf eine nachfolgende Spracheingabe vorbereitet wird.                                                                                                                                                                                                                                                                                                              | Cambridge Dictionary; Alexa Developer Documentation. ([Cambridge Dictionary][2])                                |
| **ASR – Automatic Speech Recognition / automatische Spracherkennung / Speech-to-Text (STT)** | Verfahren beziehungsweise Technologie, die gesprochene Sprache als Eingabe verarbeitet und bestimmt, was gesprochen wurde beziehungsweise Sprache in Text überführt. ASR ist eine zentrale Eingabekomponente sprachbasierter Systeme.                                                                                                                                                                                                            | NIST; IBM, *Speech Recognition*. ([NIST][3])                                                                    |
| **Assistenzsystem / alltagsunterstützende Assistenzlösung**                                  | Im Umfeld von AAL ein technisches System oder eine Kombination von Systemen und Dienstleistungen, die Menschen im Alltag unterstützen sollen. Beispiele reichen von Sensoren und Alarmfunktionen bis zu Kommunikationsdiensten und Sprachassistenten. Eine einheitliche, allgemeingültige Definition des Begriffs „Assistenzsystem“ konnte in den recherchierten Quellen **nicht belegt** werden; AAL ist hier der präziser belegte Oberbegriff. | Bundeswirtschaftsministerium, Smart Living/AAL. ([Bundeswirtschaftsministerium][1])                             |
| **Conversational Agent / dialogorientierter Agent**                                          | Computersystem bzw. Softwarekomponente, die mit Menschen über Dialog interagiert. Bei sprachbasierten Systemen erfolgt die Interaktion über gesprochene natürliche Sprache und kann mehrere aufeinanderfolgende Dialogschritte umfassen.                                                                                                                                                                                                         | Oxford Handbook, *Spoken Language Dialogue Systems*; ACM-Überblick zu Voice UX. ([OUP Academic][4])             |
| **Dialogmanagement / Dialogue Management**                                                   | Komponente eines Dialogsystems, die den bisherigen Gesprächsverlauf berücksichtigt und steuert, was das System als Nächstes tut, fragt oder ausgibt. Dazu gehören insbesondere das Verfolgen des Dialogzustands und die Auswahl der nächsten Systemaktion.                                                                                                                                                                                       | ScienceDirect, *Dialogue Management*; DST Group, *Dialogue Systems & Dialogue Management*. ([ScienceDirect][5]) |
| **Dialogsystem / Spoken Dialogue System (SDS)**                                              | Computersystem, das mit Nutzerinnen und Nutzern einen Dialog in natürlicher Sprache führt. Bei einem gesprochenen Dialogsystem ist Sprache das primäre Kommunikationsmittel. Typischerweise werden Spracheingaben erkannt, interpretiert und anschließend passende Antworten erzeugt.                                                                                                                                                            | DST Group; Oxford Handbook. ([Verteidigung DST][6])                                                             |
| **Intent / Nutzerabsicht**                                                                   | In klassischen Sprachassistenzsystemen bezeichnet ein Intent die Absicht beziehungsweise Aufgabe, die das System hinter einer Äußerung erkennt, zum Beispiel „Licht einschalten“ oder „Termin abfragen“. In der Alexa-Terminologie werden gesprochene Äußerungen bestimmten Intents zugeordnet. Eine herstellerunabhängige normative Definition konnte in den recherchierten Primärquellen **nicht belegt** werden.                              | Alexa Developer Documentation, Interaction Model / Key Terms. ([Amazon Developer][7])                           |
| **Internet of Things (IoT) / Internet der Dinge**                                            | Vernetzte Welt intelligenter Geräte, die über lokale Netze oder das Internet miteinander beziehungsweise mit Diensten verbunden sind. Die Geräte können Daten erfassen, übertragen und zur Automatisierung von Abläufen verwenden. Smart-Home-Geräte und digitale Assistenten gehören zu typischen IoT-Anwendungen.                                                                                                                              | Bundesamt für Sicherheit in der Informationstechnik (BSI). ([BSI][8])                                           |
| **Multimodale Interaktion**                                                                  | Interaktion mit einem System über mehrere Ein- oder Ausgabekanäle. Eingaben können beispielsweise Sprache, Touch, Tastatur oder Gesten sein; Ausgaben können Sprache, Text, Grafik oder andere Signale umfassen.                                                                                                                                                                                                                                 | W3C, *Multimodal Interaction Framework*. ([W3C][9])                                                             |
| **Natural Language Generation (NLG)**                                                        | Teilgebiet der Sprachverarbeitung, das natürliche sprachliche Ausgaben erzeugt. Bei einem Assistenzsystem kann NLG beispielsweise aus internen Daten oder einer Systementscheidung eine verständliche Antwort formulieren.                                                                                                                                                                                                                       | IBM, *Natural Language Generation*. ([IBM][10])                                                                 |
| **Natural Language Processing (NLP) / Verarbeitung natürlicher Sprache**                     | Teilgebiet von Informatik und KI, das Computer befähigt, menschliche Sprache in Text- oder Sprachform zu erkennen, zu analysieren, zu verstehen und zu erzeugen. NLP bildet eine technologische Grundlage vieler Sprachassistenten.                                                                                                                                                                                                              | IBM, *Natural Language Processing*. ([IBM][11])                                                                 |
| **Natural Language Understanding (NLU)**                                                     | Teilgebiet von NLP, das insbesondere Bedeutung, Absicht und Kontext natürlicher Sprache analysiert. NLU verwendet unter anderem syntaktische und semantische Analyse.                                                                                                                                                                                                                                                                            | IBM, *Natural Language Understanding*. ([IBM][12])                                                              |
| **Natural User Interface (NUI)**                                                             | Benutzungsschnittstelle, bei der die Interaktion an alltägliche, bereits erlernte menschliche Verhaltensweisen anknüpft. Typische Interaktionsformen sind Berührung, Gesten oder Sprache. „Natürlich“ beschreibt dabei insbesondere Erwartungen, Verhalten und Erleben des Nutzers, nicht eine bestimmte technische Eingabemethode.                                                                                                              | ISO/IEC 4944:2024, Definition von Natural User Interface. ([iTeh Standards][13])                                |
| **Smart Home / intelligentes Zuhause**                                                       | Sammelbegriff für vernetzte Geräte und Systeme innerhalb einer Wohnung oder eines Hauses. Dazu können Hausautomation, Haushaltsgeräte, Smart-TVs, vernetzte Lautsprecher und digitale Sprachassistenten gehören. Systeme können beispielsweise Beleuchtung, Heizung, Türen oder andere Geräte automatisieren bzw. fernsteuern.                                                                                                                   | Bundesamt für Sicherheit in der Informationstechnik. ([BSI][14])                                                |
| **Smart Speaker / vernetzter Lautsprecher**                                                  | Vernetzter Lautsprecher, der unter anderem einen digitalen Sprachassistenten bereitstellen kann und als Zugangspunkt zu Smart-Home-Funktionen dienen kann. Eine eigenständige allgemeingültige Definition wurde in den ausgewerteten Primärquellen **nicht belegt**; das BSI führt vernetzte Lautsprecher mit digitalen Sprachassistenten als Bestandteil des Smart Homes auf.                                                                   | BSI, *Smart Home*. ([BSI][14])                                                                                  |
| **Sprachassistent / Voice Assistant**                                                        | Softwarebasierter Assistent, mit dem Menschen insbesondere über gesprochene Sprache interagieren können. Sprachassistenten können beispielsweise Informationen liefern, Dienste aufrufen oder vernetzte Geräte steuern. Eine einheitliche normative Definition des deutschen Begriffs wurde in der Recherche **nicht belegt**; W3C und BSI behandeln digitale bzw. Voice Agents als sprachbasierte Interaktionssysteme.                          | W3C, *Voice Agent User Requirements*; BSI, Smart Home. ([W3C][15])                                              |
| **Speech Synthesis / Sprachsynthese**                                                        | Technische Erzeugung gesprochener Sprache durch einen Computer. Bei Sprachassistenten dient sie der akustischen Ausgabe von Antworten.                                                                                                                                                                                                                                                                                                           | W3C, JSpeech Synthesis Markup Specification; IBM TTS. ([W3C][16])                                               |
| **SSML – Speech Synthesis Markup Language**                                                  | Auszeichnungssprache zur Steuerung von Sprachsynthese. Über Markierungen kann beeinflusst werden, wie ein Sprachsynthesizer Text ausspricht beziehungsweise interpretiert.                                                                                                                                                                                                                                                                       | W3C, *Speech Synthesis Markup Language*. ([W3C][17])                                                            |
| **STT – Speech-to-Text**                                                                     | Bezeichnung für die Umwandlung gesprochener Sprache in Text. Der Begriff wird häufig synonym beziehungsweise im engen Zusammenhang mit automatischer Spracherkennung (ASR) verwendet.                                                                                                                                                                                                                                                            | IBM, *Speech Recognition*. ([IBM][18])                                                                          |
| **TTS – Text-to-Speech**                                                                     | Technologie, die geschriebenen Text in synthetisch erzeugte gesprochene Sprache beziehungsweise Audiosignale umwandelt. TTS ist eine typische Ausgabekomponente von Sprachassistenten.                                                                                                                                                                                                                                                           | IBM, *Text to Speech*. ([IBM][19])                                                                              |
| **Utterance / Äußerung**                                                                     | Die Wörter beziehungsweise sprachliche Äußerung, die ein Nutzer gegenüber einem Sprachsystem verwendet, um einen Wunsch auszudrücken oder auf eine Frage zu antworten. In klassischen Intent-basierten Systemen werden Beispieläußerungen bestimmten Intents zugeordnet.                                                                                                                                                                         | Alexa Developer Documentation, Key Terms. ([Amazon Developer][7])                                               |
| **Voice Agent**                                                                              | Ein Agent, dessen Interaktion wesentlich über Sprache erfolgt. Das W3C unterscheidet dabei einen Voice Agent mit Spracheingabe von allgemeineren Smart Agents, die mehrere Eingabemodalitäten verarbeiten können.                                                                                                                                                                                                                                | W3C, *Voice Agent User Requirements*. ([W3C][15])                                                               |
| **Voice User Interface (VUI) / sprachbasierte Benutzungsschnittstelle**                      | Benutzungsschnittstelle, über die Menschen mittels gesprochener Sprache mit einem Computer, einer Anwendung oder einem Gerät interagieren. Typischerweise werden Spracherkennung für die Eingabe und Sprachsynthese für Antworten eingesetzt.                                                                                                                                                                                                    | W3C; TechTarget; ACM. ([W3C][15])                                                                               |
