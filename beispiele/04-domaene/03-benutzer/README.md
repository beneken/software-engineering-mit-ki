# User Research - Benutzer verstehen

Ein gutes Verständnis für Benutzer zu bekommen ist ein eigenes
umfangreiches Thema. User Research ist ein Teil. Es gibt verschiedene
Ansätze um aus Marktinformationen, Social-Media, Interviews, Beobachtungen
und vielen weiteren Quellen ein Verständnis herbeizuführen aus dem dann
Anforderungen an eine Software abgeleitet werden können. 

Wir zeigen hier:
 1. [Nutzungskontext erarbeiten](./01-nutzungskontext/)
 2. [Ziele und Bedürfnisse erheben](./02-beduerfnisse/)
 3. [Personas (er)finden](./03-personas/)
 4. [Taskmodelle erarbeiten](./04-taskmodell/)
 5. [Usability Szenarios ableiten](./05-szenarios/)

Auf der Grundlage der Bedürfnisse, Personas und Taskmodelle können wir dann
Unterstützungsbedarfe ermitteln, die wir dann hoffentlich durch unser
Produkt (Software, Organisation, Menschen, ... ) abdecken können.

Achtung: Die Beispiele sind vollständig mit KI generiert (speziell die Interviews), bzw. wurden von KI-Agenten aus dem Internet extrahiert (die Studien). Sie sollen einen ersten Eindruck vermitteln. In einem realen Kontext müssen die Prompts entsprechend angepasst werden. Interviews und Beobachtungen müssen mit realen Menschen geführt werden!

Hoffe, dass ich im Laufe des Winters noch reale Interviews aus einem echten Projekt anbieten kann.
